# 线织海洋 · 手作海洋馆

[在线体验](https://tomatodroid.github.io/yarn-ocean/) · [部署状态](https://github.com/TomatoDroid/yarn-ocean/actions/workflows/pages.yml)

以用户提供的手作照片为造型参考的互动 3D 手作海洋馆。照片仅用于参考；公开构建目录中不包含照片、图鉴或摄影栏目。

20 个独立角色有三类基础结构：双色长身鱼、圆脸鱼、扁平扇形鱼。具体造型包含柠檬潜水员、可可泡泡、柠檬小舟、莓果汽水、橘子扇、蓝色蝴蝶、蓝莓嘟嘟、黑白小鲸、玫瑰团子、海草精灵、樱花小扇、橙蓝小箭、琥珀小梭、葡萄小游侠、雾银泡泡、赤陶团团、孔雀小扇、姜饼小扇，以及体形更大的斑点巡游鱼、金色领航鱼。针织海床上有 3 只活动的毛线小蟹和 21 枚钩织扇贝。两条大鱼的体形、鳍尾明显大于普通鱼，并进入前景水层；图鉴展示真实模型缩略图，并用“大型游鱼”文字标识。名称是创作称呼，不代表物种。

## 运行

`python3 -m http.server 4173 --bind 127.0.0.1 --directory dist`

静态站点，无构建步骤。Three.js 0.186.1 和 OrbitControls 本地托管，许可证见 `dist/vendor/THREE-LICENSE`。

## 实现

- `dist/scene.js`：不规则粗绒条圈、分层配色、独立鳍尾、错位凸眼、嘟嘴、程序化纤维与材质。鱼头随速度方向平滑转动，长身鱼身体与尾巴波动，圆脸鱼双鳍交替拍动；核心网格和纤维使用同一变形，随游速改变摆动强度。全景轻点模型时，鱼会轻微躲闪、加快摆尾并出现短暂触碰波纹；底部选择器仍用于近看。近看时保留小幅游动，暂不执行离屏回收。
- `dist/habitat.js`：针织海床与凸起针脚、缠线礁石、钩织环形海草叶片、绒线珊瑚、海葵和海星；海水改为半径 64 的内向针织球面，180 × 180 的海床覆盖整个环绕视角；内外两圈共 20 组礁石、海草与珊瑚环绕中央海底，重复的实体绒线使用实例几何，远处省略细纤维。海草与纤维共享摆动时钟，环境网格按材质合并。手机也保留真实三维场景，不再横向压扁环境。
- `dist/swimming.js`：左右双向穿屏状态机。每条鱼保持独立速度、轻微起伏与深度变化，游出画面后等待 2–7.5 秒，再从随机一侧进入；每次入场选择较空的高度与深度。每次入场按当前观看方向选择一条水平三维路线，已在游动的鱼保留原有世界坐标和路线；转动镜头不会带着鱼群旋转。整个包围球确认离屏后才隐藏，避免可见跳转。触碰产生有界的速度脉冲，约 1.5 秒内恢复；选中的鱼暂时锁定在近看范围。
- `dist/seafloor-life.js`：扇贝由连续的绒线扇形排、放射针脚和波浪边组成；蟹壳、腿和钳子有实体绒线圈和毛边。小蟹以独立的 23 秒节奏缓慢横行、停留、换方向；降低步足频率，使爬行与实际位移相符。与海草共享可暂停的时钟。
- `dist/yarn.js`：共享实体绒线、椭圆线圈、纤维边缘与针织贴图工具，按材质合并几何；手机降低环境纤维密度。
- `dist/index.html` / `style.css`：单屏 3D 工作面、上下只、暂停、回到鱼群与操作说明。
- `dist/fish-picker.js` / `fish-picker.css`：20 张鱼群图鉴卡片，复用主渲染器从实际 3D 几何生成一次性透明缩略图，展示名字与体型；横向滚动、浏览箭头、选中高亮与自动滚入视野。手机使用单行滑动列表。支持左右键、Home/End 移动焦点，Enter/Space 选择近看。
- `dist/fish-speech.js` / `fish-speech.css`：每条鱼有四句预设中文台词，连续轻点轮换。奶油色缝线气泡跟随鱼和视角，靠边时调整位置与尾尖，避开页头、控制区和底部图鉴；鱼离开视野时隐藏。复用单一 DOM 气泡，5.2–6 秒后消失，暂停时也会正常过期，遵循减少动态效果设置。台词通过一个无障碍状态区播报，不调用 AI 或外部接口。
- `dist/fish-feeding.js`：轻点海水或游鱼投下一颗毛线点心；命中鱼时喂给它，否则选屏幕中最近的可见鱼。点心柔和移动到鱼实时的嘴部，吃到后短暂欢快摆尾、弹动，并吐出上飘淡出的缝线爱心泡泡。回复气泡优先放在鱼下方，为爱心留出空间。420ms 节流，固定复用 5 颗点心、15 个爱心；切换视图清空反馈，隐藏的鱼不再接收点心。暂停冻结现有反馈且不接收新点心；减少动态效果时即时进食、显示静态爱心，1.5 秒后按墙钟移除。所有贴图本地生成，无新增依赖或网络请求。
- `dist/pointer-tap.js`：用完整移动轨迹区分轻点和旋转，超过 7px、超过 650ms、非主键、多指、取消、滚轮与失焦均取消本次投喂。拖动后回到起点也不触发。
- `dist/app.js`：指南交互与 3D 模块错误处理。
- `dist/404.html`：返回入口。

拖动旋转，滚轮/双指缩放。轻点海水可投喂，轻点模型保留触碰回应和台词，吃到点心后表达喜欢；角色选择器用于跟随近看。展厅聚焦后使用左右方向键切换，Home/Escape 返回鱼群。暂停同时停止游动、鳍尾变形、小蟹、海草、气泡与水中微粒；继续播放时平滑起游。系统减少动态效果设置会关闭游动与相机插值。后台或离屏暂停渲染，恢复时重置帧时钟并限制非负时间步长。3D 不可用时给出清楚的错误提示与重试入口，不会重新展示用户照片。

所有模型、绒毛、纹理都在浏览器本地生成，无第三方图片或字体请求。静态核心网格按材质合并；每只鱼使用一层合并纤维；手机降低纤维数量与像素比。

## 验证

`npm test`：27 项测试，包括 11 项游动回归、8 项轻点/拖拽/多指手势测试和 8 项投喂生命周期测试；后者使用本站 Three.js 验证实时嘴部追踪、节流、固定池上限、重复使用、暂停、目标离开、减少动态反馈过期与 GPU 资源释放。

投喂更新使用 Chrome/Playwright 验证桌面 1440 × 900 与手机 390 × 844（触摸模拟）：点击/轻触投喂、爱心出现后淡出、单指旋转、拖回起点不误触、滚轮与双指缩放、连续投喂节流、暂停与恢复、图鉴近看、方向键和 Home、减少动态效果。桌面 18 次快速点击接受 3 份点心；连续投喂清空后，在固定近看视角下 GPU 资源维持 324 个几何与 7 张纹理。手机 12 次快速轻触接受 2 份点心，无横向溢出。浏览器控制台无错误或警告。实际手机硬件性能和 iOS Safari 尚未实测。

`node --test tests/swimming.test.mjs`：11 项回归检查，涵盖桌面/手机范围、30/60/120 Hz 的 180 秒模拟；验证左右穿行、离屏等待与重入、可见段连续位移、暂停、触碰衰减和近看锁定，另检查镜头换向不移动已有鱼、斜向三维路线的触碰与重入。实际浏览器检查左右穿屏、离屏再入场、点击时保持全景且触发回应、小蟹缓慢位移、手机布局和近看；环绕更新已检查正面、侧面、背面和俯视，手机尺寸下暂停后旋转验证鱼蟹世界坐标不变。模块引用带版本参数，避免发布后旧模块和新场景混用。视口模拟不等于真实手机硬件帧率或触摸认证。
